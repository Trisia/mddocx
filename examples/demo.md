# 第一章 深度学习实验报告

## 1.1 研究背景

近年来，深度学习技术在计算机视觉领域取得了突破性进展。卷积神经网络（CNN）作为核心架构之一，在图像分类、目标检测等任务中表现出色。

## 1.2 实验方法

实验采用 CIFAR-10 数据集，随机选取每类 100 张图片作为训练集。

![模型架构](https://www.python.org/static/img/python-logo.png)

### 1.2.1 数据预处理

图像统一缩放至 32×32，并执行随机水平翻转与归一化。

### 1.2.2 训练流程

实验按照以下步骤进行：

1. 准备数据
   1. 下载 CIFAR-10 数据集
   2. 划分训练集与测试集
2. 构建模型
   1. 定义卷积层结构
      1. 第一层：32 个 3×3 卷积核
      2. 第二层：64 个 3×3 卷积核
   2. 定义全连接层
3. 训练模型
   1. 前向传播计算损失
   2. 反向传播更新权重

表 超参数配置

| 参数 | 取值 |
|------|------|
| 学习率 | 0.001 |
| 批量大小 | 32 |
| 训练轮次 | 100 |
| 优化器 | Adam |

## 1.3 理论基础

### 1.3.1 卷积操作

卷积操作的定义为 $y = W * x + b$，其中 $W$ 是卷积核，$b$ 是偏置项。

### 1.3.2 损失函数

交叉熵损失函数：

$$
L = -\frac{1}{N} \sum_{i=1}^{N} \left[ y_i \log(\hat{y}_i) + (1-y_i) \log(1-\hat{y}_i) \right]
$$

### 1.3.3 参数更新

参数更新规则为 $w_{t+1} = w_t - \eta \cdot \nabla L(w_t)$ ，学习率 $\eta$ 通过 Adam 优化器自适应调整。

#### 1.3.3.1 学习率调度

训练过程中学习率按余弦退火策略逐步衰减，初始值为 0.001。

## 1.4 实验结果

模型在测试集上取得了 94.2% 的 Top-1 准确率，验证了深度学习方法在小样本场景下的有效性。
